User Stories6.1 AutentikasiUS-001Sebagai calon pengguna, saya ingin mendaftar akun dengan email dan password, sehingga saya dapat mulai menggunakan aplikasi.Kriteria Penerimaan: Form validasi berjalan, email verifikasi terkirim, user diarahkan ke halaman onboarding setelah berhasil daftar.US-002Sebagai pengguna, saya ingin masuk menggunakan akun Google, sehingga saya tidak perlu mengingat password baru.Kriteria Penerimaan: Tombol 'Masuk dengan Google' tersedia, flow OAuth berhasil, user masuk tanpa form password.6.2 PortofolioUS-003Sebagai pengguna, saya ingin membuat portofolio baru dengan nama dan warna, sehingga saya dapat mulai mencatat arus kas untuk keperluan tertentu.Kriteria Penerimaan: Portofolio tersimpan, muncul di dashboard, saldo awal adalah Rp 0.US-004Sebagai pemilik portofolio, saya ingin mengundang anggota via email dengan level akses tertentu, sehingga mereka dapat berkontribusi atau memantau kas komunitas.Kriteria Penerimaan: Undangan terkirim, penerima mendapat notifikasi, level akses sesuai pilihan pemilik.US-005Sebagai anggota portofolio (View Only), saya ingin melihat seluruh transaksi dan laporan portofolio, sehingga saya dapat memantau kondisi kas tanpa mengubah data.Kriteria Penerimaan: Semua menu read-only tampil, tombol tambah/edit/hapus transaksi tidak muncul.6.3 TransaksiUS-006Sebagai pengguna dengan akses Edit, saya ingin menambahkan transaksi pemasukan atau pengeluaran, sehingga arus kas tercatat dengan akurat.Kriteria Penerimaan: Transaksi tersimpan, saldo portofolio langsung diperbarui, muncul di daftar transaksi.US-007Sebagai pengguna, saya ingin mengunggah foto bukti transaksi, sehingga saya punya dokumentasi yang lengkap.Kriteria Penerimaan: File maks 5 MB berhasil diupload, URL tersimpan, dapat dilihat di detail transaksi.US-008Sebagai pengguna, saya ingin memfilter transaksi berdasarkan tanggal dan kategori, sehingga saya dapat menemukan transaksi tertentu dengan cepat.Kriteria Penerimaan: Filter bekerja akurat, hasil pencarian tampil tanpa reload halaman.6.4 LaporanUS-009Sebagai pengguna, saya ingin mengunduh laporan mutasi dalam format PDF, sehingga saya dapat mencetak atau mengirimkan laporan secara formal.Kriteria Penerimaan: PDF tergenerate dalam < 10 detik, format sesuai spesifikasi mutasi, dapat diunduh.US-010Sebagai pengguna, saya ingin mengunduh laporan mutasi dalam format Excel, sehingga saya dapat mengolah data lebih lanjut di spreadsheet.Kriteria Penerimaan: File .xlsx tergenerate, kolom sesuai spesifikasi, angka dalam format numerik bukan teks.7.
